github-actions — live microservices demo

Every button below is a real HTTP request through the running pipeline's deployment: browser → ingress → frontend (nginx) → the service's pod. The frontend is a thin nginx that proxies /api/* to the three backends — no request ever talks to a pod directly.

1 · Facts — the Python service

GET /api/facts?topic=<input>

this request went ingress → frontend (nginx) → facts pod (Python :8000)

2 · Count — the Node service

POST /api/count · body {"text": "…"}

this request went ingress → frontend (nginx) → counter pod (Node :3000)

3 · Image — the Go service

GET /api/image?topic=<input>

this request went ingress → frontend (nginx) → image pod (Go :8080)
